# Dr Deblina Das Tarot Reading Website

Static one-page website for Dr Deblina Das, professional Tarot card reader.

## Files

- `index.html` - Website content and page structure
- `styles.css` - Responsive visual styling
- `assets/deblina-tarot-portrait.png` - Tarot-themed hero portrait generated from the supplied photo
- `assets/deblina-original.jpeg` - Original supplied photo
- `assets/deblina-upi-qr.jpeg` - Supplied UPI QR payment image
- `vercel.json` - Vercel static hosting configuration

## Preview Locally

From this folder:

```bash
python3 -m http.server 3000
```

Open:

```text
http://localhost:3000
```

## Deploy On Vercel

1. Create a new Vercel project.
2. Import this folder or the GitHub repository containing these files.
3. Framework preset: `Other`.
4. Build command: leave blank.
5. Output directory: leave blank.
6. Deploy.
